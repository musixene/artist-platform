Artist Branding

Listening credits remain disabled.

Invitations

Each invitation creates one listener account. Share its token privately; it is shown only once.

Listeners & administrators

Saving an account revokes its sessions. The last active administrator must remain enabled.

Tracks

Create a hidden draft, upload audio, then make it available. Release status is a separate artist-supplied designation. Position controls library and dynamic catalog order (lowest first). Audio: WAV, MP3, M4A or Ogg, up to 512 MiB. Artwork: PNG or JPEG, up to 5 MiB. Upload only trusted files you have rights to distribute.

Catalogs

Curated catalogs preserve your chosen order; dynamic catalogs follow metadata filters. Catalog availability never exposes a hidden track.
